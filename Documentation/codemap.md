# Code map

Navigation index: concept → owning file → entry points → invariants. Read the
matching concept row and package section, then the source and its tests.
Paths are repository-relative; files in a package section are in that
package. Use codebase-memory-mcp (`search_graph`, `trace_path`,
`get_code_snippet`) with `project="xdb"` (see [MCP.md](MCP.md)); check the
index status before treating a miss as absence.

- [AGENTS.md](../AGENTS.md): contribution rules and validation commands.
- [design/QUERYBUILDER.md](design/QUERYBUILDER.md): how clients write CRUD
  with generated schema, `QueryParams` and `xsql`.

  `typesmap.yaml` and the generated code.

  not edit or use for source discovery.

## Module layout

```text
*.go            package xdb: provider, transactions, value types, IDs, query params, query execution
xsql/           SQL statement builder, dialects, query cache, executor
schema/         table/column metadata (TableInfo) and DB schema introspection
migrate/        golang-migrate wrapper
pkg/flake/      snowflake ID generator
pkg/notifier/   PostgreSQL LISTEN/NOTIFY listener
pkg/print/      table/JSON/YAML printers for xdbcli
cmd/xdbcli/     schema CLI binary
internal/cli/   xdbcli context and commands (schema print, model generator)
mocks/          gomock mocks of xdb.Provider and schema.Provider (go:generate)
testdata/sql/   local PostgreSQL / SQL Server test DB scripts and migrations
testdata/e2e/   generated sample models (make gen-sql-schema, gitignored)
```

### xdb (root)

Provider, value types, IDs, query params and query execution.

- doc.go: package overview and a usage example
- db.go: IDGenerator, Row, Rows, RowScanner, DB, Tx, Provider, Open, MigrationConfig, NewProvider, Source, ParseConnectionString; go:generate for mocks/mockxdb
- prov.go: SQLProvider, New, WithConnectionString, ConnectionString, Name, BeginTx, Commit, Rollback, Close, DB, Tx, NextID, IDTime, QueryContext, QueryRowContext, ExecContext
- id.go: ID, NewID, MustID, ParseID, TryParseID, IDArray (NewIDArray, IDArrayFromStrings, Add, Concat, Contains, Overlaps, Sort, List, Strings, Int64Array), Int64Array, ID32, Enum, Int32Array
- types.go: MaxLenForName, MaxLenForEmail, MaxLenForShortURL, ErrorNotFound, NewErrorNotFound, CheckNotFoundError, IsNotFoundError, Validator, Validate, NullTime, TimePtr, String, QuotedString, ParseUint, IDString, QuotedIDString, Strings, Metadata, KVSet, NULLString, UUID, Int64, Int32, Float, Bool
- time.go: Time, Now, UTC, FromNow, FromUnixMilli, ParseTime, DefaultTimeFormat, DefaultTrucate
- params.go: PageableByOffset, PageableByCursor, HasQueryParams, GetQueryParams, QueryParams, QueryParamsBuilder, NewQueryParams, PageParam
- query.go: DefaultPageSize, RowPointer, QueryRow, QueryRows, ExecuteListQuery, Result, ResultWithCursor, SetCursor, ExecuteQueryWithPagination, ExecuteQueryWithCursor, ExecuteQuery, EncodeCursor and DecodeCursor (deprecated)
- cursor.go: Cursor, NewCursor, ParseCursor, String, IsZero, Len, Scan
- merge.go: Merge, MergeOpts

Invariants:

- Open resolves the data source through configloader (`file://`, `env://`),
  opens and pings it, and appends the database name as a query parameter
  (`&dbname=` for postgres, `&database=` for sqlserver), so the URL must
  already have a query string (`?sslmode=disable`). Drivers: `postgres`,
  `sqlserver`. Connection idle time and lifetime are unlimited.
- NewProvider runs migrations only when `MigrationConfig.Source` is set,
  then wraps the `*sql.DB` with New; on an error it closes the DB. New
  starts a 60-second keep-alive ping goroutine; Close stops it and closes
  the DB, and is idempotent.
- BeginTx returns a Provider bound to the transaction and passes its
  `TxOptions` to the driver; it does not nest ("transaction already
  started"). Close on a transaction provider rolls back, which is a no-op
  after Commit, so `defer tx.Close()` then `tx.Commit()` is the pattern.
- Two ID generator interfaces exist: `xdb.IDGenerator` (`NextID() ID`, used
  by providers) and `pkg/flake.IDGenerator` (`NextID() uint64`), which New
  and NewProvider take; nil is flake.DefaultIDGenerator, and a
  `github.com/effective-security/x/flake` generator also fits.
- ID is `type ID uint64`: zero is invalid and NULL, `String()` of zero is
  empty, comparable and ordered; `json:",omitempty"`, the tag of every
  generated column, omits a zero ID. IDArray scans and writes a PostgreSQL
  int8 array; Add and Concat deduplicate (quadratic), Sort sorts in place.
- NULL mapping: the zero value of ID, ID32, Int64, Int32, Float, Bool,
  NULLString, UUID and Time writes NULL; empty Metadata and KVSet write NULL
  (a NOT NULL jsonb column needs the caller to write `{}`); nil Strings
  writes NULL. NULL scans back to the zero value.
- Time is always UTC; Now, UTC, FromNow, ParseTime and Add truncate to
  DefaultTrucate (millisecond). Scan accepts a string (ParseTime) or a time;
  JSON of the zero time is `""`.
- QueryParamsBuilder records set positions (0..63, the generated
  `Column.Position`) in a bit mask; Name is the query name plus the mask,
  enum values, flags, `_c` (cursor) or `_o` (offset > 0) and a hash of the
  null columns, recomputed after every change. Set, AddArgs and SetEnum
  after SetPage or SetCursor panic. SetCursor(limit, pos, key...) adds the
  key values as positional arguments, then the limit; Cursor() returns the
  single value or the `[]any` key; without key values SetCursor is
  SetPage(limit, 0). SetFlags replaces the flags. SetNullColums keeps a
  sorted copy. Reset keeps only the query name.
- The query helpers are package functions over `DB`: Go 1.27 allows type
  parameters on methods of concrete types only, not on interface methods.
  QueryRows yields rows through `iter.Seq2`, closes them when the loop ends
  and yields a query, scan or `rows.Err()` error once; the list helpers
  collect through it, preallocating up to the page limit.
- ExecuteQueryWithPagination takes limit and offset from QueryParams or the
  last two positional arguments, ExecuteQueryWithCursor the limit from
  QueryParams or the last of two or more arguments; a lone positional
  argument is not a limit (it can be a filter value), so a limit-only query
  passes QueryParams. In QueryParams the limit argument is
  the last one after SetCursor with a key and the one before the offset
  after SetPage (paramsLimitAt). executePage binds limit+1 on a copy of the
  arguments, returns at most limit rows and reports a next page only when
  the extra row exists; the LIMIT must apply to the final ordered result,
  not to a subquery the outer query reorders. When the argument does not
  hold the limit (peekLimit: int, uint32 or sql.NamedArg equal to it, below
  MaxUint32) the query runs as is and a full page reports a next page. A
  zero limit reports none. ExecuteQuery does not page. QueryRow returns the
  driver error with a stack; map `sql.ErrNoRows` with CheckNotFoundError.
- Cursor holds the sort key as text: Time and time.Time as RFC 3339 with
  nanoseconds, then custom text methods (MarshalText on the value or its
  pointer), then integer kinds as decimal digits and strings as is; a
  pointer encodes its value. Its token is base64url (no padding) of a JSON
  array of strings. NewCursor returns an error for a failing MarshalText or
  an unsupported type instead of a fallback token. Scan checks for a non-nil
  pointer first, then decodes
  in the same order (UnmarshalText before the kind) and fails on a
  different number of values. Cursors are not signed.
- Merge overrides dst with src fields; a zero ID, Time or NULLString in src
  never overrides dst.

Tests: db_test.go needs PostgreSQL and SQL Server (TestPGKeyset,

### xsql

SQL statement builder and executor; see [xsql/README.md](../xsql/README.md)
and doc.go.

- dialect.go: SQLDialect, Dialect, NoDialect, Postgres, SQLServer, SetDialect, UseNewLines, WithNewLines, Provider, New, With, From, Select, Update, InsertInto, DeleteFrom
- stmt.go: Builder, Row, Stmt (Select, From, Where, In, NotIn, Join, LeftJoin, RightJoin, FullJoin, CrossJoin, Set, SetExpr, NewRow, OnConflict, Returning, OrderBy, GroupBy, Having, Limit, Offset, Paginate, ForUpdate, ForShare, With, SubQuery, Union, Clause, Expr, To, Bind, Clone, String, Args, Dest, SetName, Close); package-level constructors use the default dialect
- cache.go: GetCachedQuery, PutCachedQuery, GetOrCreateQuery, ClearCache
- executor.go: Executor, Query, QueryAndClose, QueryRow, QueryRowAndClose, Exec, ExecAndClose
- pool.go, bind.go, util.go: statement pool, reflect field cache for Bind

Invariants:

- Clauses render in a fixed order (WITH, INSERT, VALUES, ON CONFLICT,
  DELETE, UPDATE, SET, SELECT, FROM, WHERE, GROUP BY, HAVING, UNION, ORDER
  BY, LIMIT, OFFSET, FOR UPDATE/SHARE, RETURNING), not call order; `Clause`
  appends after the last clause added. Postgres numbers `?` in rendered
  order and leaves a literal `$n` unchanged; Args follows rendered order.
- Limit and Offset render `LIMIT ?` / `OFFSET ?` with their value as an
  argument. Where calls are joined with AND; there is no OR helper.
- Dialects are safe for concurrent use, statements are not: Clone a
  template or build per goroutine, and Close every statement (or use an
  `*AndClose` method). `With`, `SubQuery` and `Union` close the builder they
  take.
- Stmt.String caches the rendered SQL per dialect keyed by the raw builder
  text and by SetName. The cache holds 4096 entries; a full cache stops
  caching new entries. WithNewLines shares the cache of its parent.
- GetOrCreateQuery returns the cached SQL for a name or renders and caches
  the builder returned by create, which it closes; the builder's arguments
  are discarded. Clone does not copy the name.
- process-global: the default dialect (atomic), each dialect's cache
  (mutex), the statement pool and the Bind field cache (sync.Map).

Tests use in-memory sqlite (executor_test.go) and PostgreSQL;
example_test.go holds the runnable examples.

### schema

Table metadata for generated code and schema introspection for xdbcli.

- schema.go: HasTableInfo, TableInfo (From, DeleteFrom, InsertInto, Update, Select, SelectAliased, AllColumns, AliasedColumns), Table, Tables, Column (StructString, IsIndex, IsPrimary, Tag), Columns, Index, Indexes, ForeignKey, ForeignKeys, Provider; go:generate for mocks/mockschema
- provider.go: Dialect, SQLServerProvider (the implementation for every dialect), NewProvider, ListTables, ListViews, ListForeignKeys
- postgres.go, sqlserver.go: the introspection queries per dialect

Invariants:

- TableInfo builders start from `SchemaName` (`schema.table`) on the
  table's Dialect. AllColumns joins the columns on every call and writes
  nothing, so generated tables are safe to share (tableinfo_test.go).
- ListTables with dependencies adds every table reachable through foreign
  keys, in any schema, and sets Column.Ref. Column.SchemaName is
  `schema.table.column`, Position the 1-based ordinal. Table.Indexes are
  sorted by index name and Index.ColumnNames follow the index key order.

Tests need PostgreSQL and SQL Server.

### migrate

golang-migrate wrapper. migrate.go: Migrate.

Invariant: an empty directory is a no-op; migrations are read from disk
(`file://<dir>`); providers `postgres`, `pgsql` and `sqlserver`. A positive
forceVersion forces that version first; a positive migrateVersion migrates
to it, otherwise Up; "no change" is success.

### pkg/flake

Snowflake ID generator. flake.go: IDGenerator, DefaultIDGenerator, NowFunc,
Settings, Flake, NewIDGenerator, NextID, Decompose, IDTime, FirstID, LastID,
IsTestRun.

Invariant: 63-bit IDs of 41 bits time (FlakeTimeUnit, 1 ms, since
DefaultStartTime 2021-01-01), 6 bits sequence and 16 bits machine ID;
DefaultIDGenerator is created at init and NowFunc is replaced in tests. The
default machine ID is the lower 16 bits of the first non-loopback address,
a hash of the program name in test binaries (IsTestRun is
`testing.Testing()`), or 0 without an address.

### pkg/notifier

PostgreSQL LISTEN/NOTIFY on lib/pq. listener.go: Listener, NewListener,
Listen, Close, Notification.

Invariant: NewListener connects with the provider's ConnectionString.
Listen subscribes and returns; a goroutine calls the callback with the
payload parsed as JSON until the context ends, then unlistens, and pings
the connection after a minute without events.

### pkg/print

Output for xdbcli. print.go: JSON, Yaml, Object, Print; schema.go:
SchemaTables, SchemaTable, SchemaIndexes, SchemaForeingKeys.

### cmd/xdbcli

The schema CLI. main.go: realMain parses `internal/cli.Cli` plus
`schema.Cmd` with kong. buildVersion returns `main.version` (set with
`-ldflags` by `make build`), else the module version of a `go install`
build, else `devel`.

### internal/cli

xdbcli context. cli.go: Cli (`--debug`, `--o`, `--sql-source`), AfterApply,
DB, SchemaProvider, WithSchemaProvider, Context, Reader, Writer, Print.

Invariant: AfterApply takes the source from `--sql-source` or

### internal/cli/clisuite

CLI test suite with captured output: TestSuite, HasText, HasNoText,

### internal/cli/schema

xdbcli `schema` commands and the model generator.

- schema.go: Cmd, GenerateCmd, PrintColumnsCmd, PrintTablesCmd, PrintViewsCmd, PrintFKCmd, override (typesmap keys: tables, fields, types, with_cached_props, drop_columns), generate, goName, tableStructName, tableInfoStructName, columnStructName
- template.go: tableDefinition, schemaDefinition, codeHeaderTemplateText, codeModelTemplateText, codeTableSchemaTemplateText, codeSchemaHeaderTemplateText
- types.go: typesMap, fieldNamesMap, tableNamesMap, modelWithCacheMap, typeByColumnType, isID, toGoType

Invariants:

- Type resolution (toGoType): `types` by bare column name, then by
  `schema.table.column`, then the `_count` rule, ARRAY rules, then
  typeByColumnType with the ID heuristic (`id`, `*_id`, `*Id`, `*ID` map
  bigint to xdb.ID); an unknown type or array panics.
- Output is one `model.gen.go` and one `schema.gen.go` per run, in table
  order, formatted with go/format; no file when no table matches. Names
  are not qualified by the schema (TableInfo names, `<Db>Tables` keys), so
  each schema with clashing table names needs its own output folders.
  Imports are exact: the model imports errors, xdb and xdbschema, the
  sibling schema package by the path from the nearest `go.mod`
  (importPath), and pq, values and the `--imports` packages (userImport)
  that the parsed column types refer to (typePackages); an `--imports`
  package replaces the known pq or values of its name, and importSpecs
  keeps one import per name and path (goImport). The schema file imports
  xdbschema and xsql.
- The override maps are process-global and filled from `--types-def`.

Tests: generate_test.go generates two schemas into a module and checks
imports and declarations; schema_test.go drives the commands through mocks/mockschema and
testdata/pg_columns.json, pg_tables.json; template_test.go holds the type
mapping tables.

## Build, test and CI

- Go 1.27 (`go.mod`). `make tools` installs golangci-lint, govulncheck,
  cov-report, mockgen and gomarkdoc. `make build` builds `bin/xdbcli`.
- Local fixtures: `make start-localstack start-sql` starts PostgreSQL
  (`127.0.0.1:15433`) and SQL Server (`127.0.0.1:11434`) and creates
  `testdb` from `testdata/sql`; `make drop-sql` drops it.
- `make test` (`RACE=true` for the race detector), `make testshort`,
  `make covtest`; `make lint` runs fmt, vet and golangci-lint.
- `make gen-sql-schema` regenerates `testdata/e2e` with the `xdbcli` on
  `PATH` and runs goimports. `make build` sets the xdbcli version from
  `GIT_VERSION`; a `go install` build reports its module version.
- `make build docs` regenerates `Documentation/api/` (gomarkdoc) and
  `Documentation/cli/` (xdbcli help).
- `.github/workflows/unittest.yml`: on pushes to main and PRs, prepares the
  local stack and runs `make build covtest`; PRs get a coverage status
  against `MIN_TESTCOV` (80). Lint and race checks are local.
  `settag.yml` (manual) tags `<.VERSION>.<commit count>`.
